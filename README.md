\# Test Result Analysis of a 4-bit Adder



A Python case study that compares expected and actual outputs of a simulated

faulty 4-bit adder, counts PASS/FAIL results and finds the bug pattern

(carry lost when A + B > 15).



\## What it covers

\- Lists, dictionaries, loops, if/else, user-defined functions

\- Pass/fail checking and pass percentage

\- Matplotlib charts of results



\## Files

\- `adder\_test\_result\_analysis.ipynb`: executed notebook with outputs and plots

\- `report.pdf`: case study report



\## Result

20 test cases: 12 passed, 8 failed (60%). All failures occur when A + B > 15.



\## Tools

Python, Matplotlib, Jupyter (VS Code)
